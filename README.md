# Portfolio Website

Personal portfolio built with React + Vite, showcasing my projects, skills, and background.

## Tech Stack
- React + Vite
- Formspree (contact form backend)
- Google reCAPTCHA v2

## Setup
1. `npm install`
2. Add `.env` with `VITE_RECAPTCHA_SITE_KEY=your_key`
3. `npm run dev`
